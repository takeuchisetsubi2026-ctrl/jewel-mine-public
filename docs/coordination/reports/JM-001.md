## 4. 所有者に必要な確認

まず両アイコンをそれぞれ長押し→アプリ情報を開き、次の情報を可能な範囲で取得する。スクリーンショットでも文字の記録でもよい。削除・初期化はしない。

1. アイコンとAndroidアプリ情報の表示名、Androidバージョン。
2. 表示される場合はパッケージ名、インストール元、個人／仕事用等のプロファイル。
3. ゲーム下部の表記と、現在のSCORE・BEST・盤面の控え。
4. ブラウザ管理のアプリなら、そのインストール元と起動URL。認証情報を含むURL等は公開しない。

設定画面だけでversionCode・署名・コミットを確認できない端末もある。その場合は未確認のままにし、推測しない。スマホだけで識別できなければ次の操作へ進めない。

PCを使える場合の読み取り専用の補助手段：

- 所有者が許可したUSBデバッグでadb shell pm list packages、adb shell dumpsys package <確認したID>。
- adb shell pm path <確認したID>でAPKの場所を確認し、adb pullでAPKだけを複製。
- aapt dump badging、apksigner verify --print-certs、APK内HTMLのハッシュ比較。
- 既存版にSHAが埋め込まれていない場合、完全一致する公開成果物がなければコミットは「不明」とする。

pm clear、アンインストール、run-as等による保存書換え、実データの公開は行わない。追加の解析アプリ導入を必須にしない。
