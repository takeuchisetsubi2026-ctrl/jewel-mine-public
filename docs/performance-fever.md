# パフォーマンス改善・FEVER変更の検証

対象: `index.html`（公開エントリ）。元コミット: `d5ffa1e`。
復元用ローカルブランチ: `backup/before-performance-fever-20261024`。
`index 31.html` とZIP内の旧版は変更しない。

## 変更

- FEVER: 55.2 → 82.8px、390px幅以下は48 → 72px（150%）。極端に狭い画面では24vwを上限として収める。各文字の虹色と白縁を維持。
- 表示: 1000 → 1250ms。FEVER開始760ms後からの表示を確保するため、同時全消しのALL CLEAR通知を2110ms後へ移動。
- 消去: 1セル9粒 → 5粒。最大16セルを均等に抽出。白い閃光・破片・金色の火花・衝撃波・複数消去の光線を維持。重なる演出は2グループまで。
- 盤面64セルは再利用。手札は従来どおり更新。
- スコアの幅調整はロール開始・終了時に実施し、各フレームの強制レイアウトを削減。
- 保存は従来どおりrender時に同期保存。64セルの小さい状態データであり、遅延保存による終了時の取りこぼしを避ける。localStorageのAndroid実機I/O時間は未計測。
- FEVERの5手・2倍、得点式、コンボ、宝石、保存形式は変更なし。
