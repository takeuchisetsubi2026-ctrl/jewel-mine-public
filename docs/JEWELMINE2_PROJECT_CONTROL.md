- 調査・自動化・管理整備は上記のクリティカルパスを妨げない範囲に限定する。
- ChatGPTの記憶、過去の報告、GitHubの実物、実機結果を区別する。矛盾したら原本・ログ・検証証拠を優先。
- 作業報告は「● 完了（結果確認済み）」「◐ 作業中（実際に進行中）」「○ 未完了」。推測で完了扱いしない。
- 進捗率は直近の報告値 **ゲーム本体40%／Android実機40%／Google Play公開20%** を暫定据置。採点基準と証拠が定まるまで再計算しない。

- 既存ゲーム本体、既存アプリID、署名鍵、保存データを無断変更しない。

- Play Protectを無効化させない。アンインストール・データ削除を勝手に指示しない。
