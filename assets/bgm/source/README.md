# N1 / L1 supplied extracts

The two `ORIGINAL.js` files are byte-preserved extracts supplied in the first
2026-11-10 ZIP. The `AUDITION_ENGINE.js` files are the complete script-element
contents recovered from the jmn14 and jmfl audition AppBlocks in the second ZIP.

`node tests/bgm-source.cjs` checks all eight bars, durations, chords, bass and
hashes, and proves that N1/L1 are exactly the first tracks in the recovered
audition engines. The game integrates only those two selected tracks.
